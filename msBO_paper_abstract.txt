Complex objective functions in accelerator optimization often involves experiments performed at multiple machine states — distinct optics configurations, beam energies, or magnet settings — where the same control knobs are shared across states and the objective depends on combined outputs from all of the states. A simple example is beam trajectory centering at quadrupole magnet: corrector magnets serve as controls, beam position monitors (BPMs) provide observables, each quadrupole configuration defines a machine state, and the objective is determined by the combined beam response across all states. Such a task is particularly challenging when switching machine state is costly, since evaluating the objective requires information from every state.
We present a Bayesian optimization framework that handles this structure. A multi-task Gaussian process (MTGP) models all states and their observables jointly, learning correlations both within and across machine states. This allows measurements from one state to update predictions about all others, reducing the number of state switches needed. The acquisition function optimizes the composite cross-state objective directly — without requiring all states to be visited at every iteration — by leveraging the MTGP posterior over unvisited states. We validate the approach in numerical simulation, and present preliminary results from beam-based tests.
